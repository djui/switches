Switches

Every keystroke, a real switch.

A native macOS menu bar app with spatial stereo, ten themes, and a Settings panel that goes deep. Try the sound below — click the keys or just start typing.

Type. Hear the switch. Move left, hear left.

In the app — and in this demo — each key plays from the side of the stereo field that matches its place on the keyboard. Key-down and key-up are separate samples, with a little random pitch and volume so nothing feels looped.

Everything in Settings

The menu bar is for quick theme, volume, and pause. The Settings window is where Switches becomes yours.

General

Launch & layout

  • Launch at login via macOS Login Items, with a shortcut when approval is required
  • Keyboard layout — ANSI, ISO, or JIS — so spatial panning matches your physical board
  • Input Monitoring status and a one-click path to grant permission

Sound

Tone & space

  • Volume with live % readout (also on the menu bar)
  • Theme picker plus an in-app Preview button
  • Stereo width — how hard left/right keys pull to each speaker
  • Headphone mode — adds a short interaural delay for a wider image on headphones
  • Pitch variation and volume variation so presses never sound identical
  • Key-up level — how loud release samples sit under the downs
  • Ignore key auto-repeat so held keys don’t machine-gun
  • A note when Bluetooth output adds unavoidable latency

Pausing

Quiet when it counts

  • Pause sounds toggle (same as the menu bar)
  • Global hotkey ⌃⌥⌘K (optional)
  • Auto-pause while a game is in front
  • Auto-pause in full screen
  • Auto-pause during secure text entry (password fields)
  • Excluded apps list — mute while chosen apps are frontmost; add from what’s running

Native where it matters

  • Menu bar first

    Theme, volume, pause, and Settings — always one click away. No dock clutter; Switches is an agent app.

  • Instant feedback

    Listen-only key capture and a low-latency audio engine. Wired or built-in speakers stay snappy.

  • Private by design

    Input Monitoring sees key codes for sound and pan only. Nothing is logged or sent — the app has no network entitlement.
