Switches

Every keystroke, a real switch.

A native macOS menu bar app that plays high-fidelity mechanical keyboard sounds — spatial, instant, and quiet when you need it.

Download for Mac View on GitHub

Type. Hear the switch.

Switches listens for key down and key up, then plays the matching sample from the side of the stereo field that matches the key — left keys left, right keys right — with a touch of random pitch so nothing repeats the same way twice.

Built to disappear into the bar

  • Spatial & instant

    Low-latency native audio engine. Key position drives stereo pan; pitch and gain vary slightly on every press.

  • Pause when it matters

    One click, ⌃⌥⌘K, or auto-pause for games, full-screen apps, and password fields.

  • Yours to tune

    Volume and launch at login in Settings. Theme, stereo width, and variation live next to the menu bar controls.

Put switches under your fingers.

macOS 15+. Grant Input Monitoring once — Switches never records what you type.
